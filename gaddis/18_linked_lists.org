* Overview
  #+attr_html: :width 200px :float nil: 
  [[../img/cangaroo.png]]

  - What is a *linked list*?
    #+begin_quote
    A linked list is a series of connected *nodes* where each node is a
    data structure and contains a reference to other data structures. A
    linked list can shrink or grow as the program runs because the nodes
    are dynamically allocated: If a node needs to be added or removed,
    the memory is allocated or deleted.
    #+end_quote

  - What's the advantage over arrays and vectors?
    #+begin_quote
    1. The programmer does not need to know how many nodes will be in
       the list, compared to arrays.
    2. The creation or deletion of nodes is often faster than for
       vectors.

    | Operation          | vector         | singly/doubly linked list    |
    |--------------------+----------------+------------------------------|
    | Access (by index)  | O(1)           | O(n)                         |
    | Insertion (end)    | O(1) amortized | O(1)                         |
    | Insertion (middle) | O(n)           | O(n) traversal, O(1) at node |
    | Deletion (end)     | O(1)           | O(n) singly, O(1) doubly     |
    | Deletion (middle)  | O(n)           | O(n) traversal, O(1) at node |
    | Search (linear)    | O(n)           | O(n)                         |

    #+end_quote

* Composition of a Linked List
#+attr_html: :width 600px :float nil:
#+caption: Composition of a linked list
[[../img/linked_list.png]]

- Each node consists of a data part and of a pointer. The pointer
  points at the next list element. At the head of the list is a
  pointer known as the *list head*, and at the end is a ~nullptr~
  (pointing to the ~NULL~ address).

- In reality, the nodes can be scattered across memory (that's one of
  the list's strengths, not to have to be in contiguous memory).

* Creating a linked list

- Decide on a data structure used for the nodes (that hold data +
  pointer). For example: a ~struct~
  #+begin_src C++ :main yes :includes <iostream> <cstdlib> <string> <fstream> <vector> :namespaces std :results output :exports both :noweb yes
    struct ListNode
    {
      double value;
      ListNode *next;
    }
  #+end_src

- Since =ListNode= contains a poitner to an object of the same type, it
  is a *self-referential* data structure.

- To activate/start the list, you need to define a list head:
  #+begin_example C++
    ListNode *head;
  #+end_example

* Glossary

| Term                    | Explanation                               |
|-------------------------+-------------------------------------------|
| *linked list*             | A dynamic series of nodes with pointers.  |
| *node*                    | Contains data and pointer to next node.   |
| *list head*               | Points to the first node in the list.     |
| ~nullptr~                 | Marks the end of the list (null pointer). |
| *self-referential struct* | A struct with pointer to same type.       |
