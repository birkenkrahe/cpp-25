* Reading a file into an array

- How can you read the contents of a file into an array?
  #+begin_quote
  Open the file and read each item from the file storing each item in
  an array element until either the array is filled or EOF is reached.
  #+end_quote

- Example: We put 10 numbers into a file =TenNumbers.txt= and read these
  numbers into an array.

- Input file:
  #+begin_src bash :results output :exports both
    cd ../data
    echo "101 102 103 104 105 106 107 108 109 110" > TenNumbers.txt
    cat TenNumbers.txt
  #+end_src

  #+RESULTS:
  : 101 102 103 104 105 106 107 108 109 110

  #+name: Program 7-7 Gaddis page 398
  #+begin_src C++ :results output :tangle file2array.cpp
    // file2array.cpp: read data from a file into an array
    #include <iostream>
    #include <fstream>
    using namespace std;

    int main()
    {
      const int ARRAY_SIZE = 10;  // Array size
      int numbers[ARRAY_SIZE]{0}; // Array of 10 elements (init 0)
      int count = 0;              // Loop counter
      ifstream inputFile;         // Input file stream object

      // Open the file
      inputFile.open("../data/TenNumbers.txt");

      // Read numbers from the file into the array
      while (count < ARRAY_SIZE &&
         inputFile >> numbers[count])
        count++; // next array element

      // Close the file
      inputFile.close();

      // Display the numbers read
      cout << "The numbers are: ";
      for (count=0; count<ARRAY_SIZE; count++)
        cout << numbers[count] << " ";

      return 0;
    }
  #+end_src

  #+RESULTS: Program 7-7 Gaddis page 398
  : The numbers are: 101 102 103 104 105 106 107 108 109 110

- The ~while~ loop test two Boolean conditions, which must both be ~true~:
  1) =count < ARRAY_SIZE= so that we don't write past the end of the
     array.
  2) =inputFile >> numbers[count]= reads value from the file and stores
     it in an array element. If no value can be read (e.g. because the
     file is empty or the EOF is reached), the loop stops.

* Writing an array to a file

- How can you write the contents of an array to a file?
  #+begin_quote
  Use a loop to step through each element of the array, writing it to
  file.
  #+end_quote


- Example:
  #+name: Program 7-8 Gaddis page 400
  #+begin_src C++ :results output :tangle array2file.cpp
    // array2file.cpp: write contents of an array to a file
    #include <iostream>
    #include <fstream>
    using namespace std;

    int main()
    {
      const int ARRAY_SIZE = 10;  // array size
      int numbers[ARRAY_SIZE]{0}; // array of 10 elements (init 0)
      int count;                  // loop counter
      ofstream outputFile;        // Output file stream object

      // initialize array
      for (count=0; count < ARRAY_SIZE; count++)
        numbers[count] = count+100;

      // Open a file for output
      outputFile.open("../data/SavedNumbers.txt");

      // Write the array contents to the file
      for (count=0; count < ARRAY_SIZE; count++)
        outputFile << numbers[count] << endl;

      // Close the file
      outputFile.close();

      // Print success message
      cout << "The numbers were saved to the file.\n";

      return 0;
    }
  #+end_src

4. What is the difference between an array's size declarator and a
   subscript?
   #+begin_quote
   - The *size declarator* specifies how many elements an array can
     hold — it must be a positive constant integer at compile time.
   - A *subscript* (or index) is used to access individual elements of
     the array. It can vary during program execution, typically in a
     loop. The valid range of subscripts is from 0 to =SIZE - 1=.
   #+end_quote

5. What is "array bounds checking"? Does C++ perform it?
   #+begin_quote
   - *Array bounds checking* refers to the process of verifying that
     array subscripts are within the valid range (0 to size - 1)
     during runtime.
   - C++ does *not* perform automatic bounds checking for built-in
     arrays. Accessing out-of-bounds elements results in *undefined
     behavior*, and it's the programmer's responsibility to ensure
     safety.
   #+end_quote

* 7.4 The Range-based ~for~ loop

- This loop iterates once for each element in an array. It was
  introduced in C++11.

- General form:
  #+begin_example
  for (dataType rangeVariable : array)
      statement
  #+end_example

- Here, `dataType` is the data type of the `rangeVariable`, which
  receives a different array element during each loop iteration.

- `array` is the array the loop operates on, and `statement` is what
  you want to do in an iteration.

- Example: Use range-based iteration to display the array: 3,6,9.
  #+begin_src C++ :main yes :includes <iostream> <cstdlib> :namespaces std :results output :exports both :noweb yes
    int numbers[]{3,6,9};
    for (int val : numbers)
      cout << val << " ";
  #+end_src

  #+RESULTS:
  : 3 6 9

- You can use the ~auto~ key word to infer the data type of the range
  variable:
  #+begin_src C++ :main yes :includes <iostream> <cstdlib> :namespaces std :results output :exports both :noweb yes
    int num[]{3,6,0};
    for (auto val : num) cout << val << " ";
  #+end_src

  #+RESULTS:
  : 3 6 0

- Example: Display the elements of a ~string~ array.
  #+begin_src C++ :main yes :includes <iostream> <cstdlib> <string> :namespaces std :results output :exports both :noweb yes
    string names[]{"Jim","Joe","Jane","Jack"};
    for (auto name : names) cout << name << endl;
  #+end_src

  #+RESULTS:

  : Joe
  : Jane
  : Jack

  #+begin_quote

* Using parallel arrays (payroll program revisited)

- Using the same subscript, you can build relationships between data
  stored in two or more arrays.

- Example: A variation of the payroll [[Program 7-13 Gaddis page 409]]: we
  use two parallel arrays, one for =hours= worked by each employee,
  another one for the =payRate= paid to each employee. The subscript
  maintains the identity of the employee.

- For later reference: We could pick different approaches:
  | *Approach*                | *Description*                           | *Pros*                        | *Cons*                                    |
  |-------------------------+---------------------------------------+-----------------------------+-----------------------------------------|
  | Add a third array =empID= | Track employee ID explicitly          | Simple; easy upgrade        | Still error-prone and hard to manage    |
  | Use a 2D matrix         | Rows as employees, columns pay, hours | Compact; indexable          | No semantic clarity (what is column 1?) |
  | Use a =struct=            | Group =id=, =hours=, =rate= into one unit   | Clear, extensible, readable | Slightly more complex syntax            |
  | Use a =class=             | Add methods, encapsulate behavior     | Best for large systems      | Overkill for basic use                  |

- Using a ~struct~ is the best way:
  1. Data are bundled with minimal syntax.
  2. No behavior assumed (no methods needed like =computePay=).
  3. All members are ~public~ by default.

- Code example:
  #+begin_src C++ :tangle ../src/payroll.cpp :noeval :main no :includes :exports both :noweb yes

    #include <iomanip>
    using namespace std;

    int main() {

           << " employees and their\n"
           << "hourly pay rates.\n";

* 7.7 Arrays as Function Arguments

- To pass an array as an argument to a function, pass the name of the
  array. The name will decay to a pointer to the first array element.

- Example: =showValues= of an array

      showValues(numbers,ARRAY_SIZE);
      return 0;
    }

    {

        cout << num[i] << " ";
    }

- Wouldn't a range-based loop work in ~showValues~, too?
  #+begin_example C++
    void showValues2(int num[])
    {
      for (int val : num)
        cout << val;
    }
  #+end_example

- Answer:
  #+begin_quote
  The range-based loop inside =showValues= is invalid because it has no
  end for the range: =ARRAY_SIZE= is not passed, and even if it were
  passed, it could not be used in the loop. In C++, use ~std::array~ or
  ~std::vector~ instead, which stores size information.
  #+end_quote

- Note: If an array has been passed as an argument into the function,
  you cannot use structured binding declaration in the receiving
  function to unpack the array (since only the beginning of the array
  is available to the compiler).

* 7.11 Introduction to the STL ~vector~ (page 443)

- The ~vector~ data type of the Standard Template Library (STL) is
  similar to an array:
  1. Holds a sequence of values or elements (of one type).
  2. Stores its elements in contiguous memor locations.
  3. Can be accessed using the subscript operator ~[]~ (only on existing
     ~vector~ elements).

- Some differences:
  1. You don't have to declare the number of elements that the ~vector~
     will have.
  2. If you add a value to a ~vector~ that's already full, the ~vector~
     will automatically increase its size to accommodate the new
     value.
  3. A ~vector~ can report the number of elements it contains.
  4. To use ~vector~ you need ~using namespace std;~ in your program.

- You need to ~#include <vector>~ - check out ~cppreference~: "~std::vector~
  is a sequence container that encapsulates dynamic size arrays."
  Further down the page, you see some notes on the algorithmic
  complexity (aka efficiency) of common ~vector~ operations:

  1. Random access: O(1)
  2. Insertion or removal of elements at the end: O(1)
  3. Insertion or removal of elements anywhere: O(n)

- Important member functions: ~swap~, ~clear~, ~empty~, ~push_back~, ~insert~,
  ~resize~, ~pop_back~, ~at~.

    //******************************************************
    // avgVector accepts an integer vector as its argument *
    // If the vector contains values, the function returns *
    // the average of those values as a double. Otherwise, *

      else
        {
          for (int count = 0; count < vect.size(); count++)
            total += vect[count];
          avg = total / vect.size();
        }

* Glossary

#+caption: Pointer Glossary
| Aspect    | Pointer Example / Description                           |
|-----------+---------------------------------------------------------|
| Purpose   | Holds a memory address, can point to vars or be nullptr |
| Define    | int *p; p = &i;                                         |
| Access    | *p dereferences; p gives the address                    |
| Copy      | q = p; now both point to same object                    |
| Extend    | Use pointer arithmetic or point to other pointers       |
| Delete    | Set to nullptr; use delete if allocated w/ new          |
| Risks     | Uninitialized/dangling pointers cause UB                |
| Use cases | Linked lists, trees, function args, dynamic memory      |

#+caption: Array Glossary

|------------+------------------------------------------------|

| Define     | int a[3] = {1, 2, 3};                          |
| Access     | a[0], a[i], pointer-style: *(a+i)              |
| Copy       | Manual loop: for (i) b[i] = a[i];              |
| Extend     | Allocate new array w/ new; copy + add elements |
| Delete     | Use delete[] for dynamic arrays                |
| Storage    | Contiguous memory layout                       |
| Subscripts | Always 0 to n-1                                |
