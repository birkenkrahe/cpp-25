* C++ Command-Line Practice Worksheet (No Answers)

Follow each instruction exactly. Ask if anything is unclear.

* Step 1: Write a C++ program
Write a C++ code block that:
- Reads two integers from input
- Computes and prints their sum
- Tangles to a file named `add.cpp`

* Step 2: Tangle the code
- Place your cursor inside the code block
- Tangle it into `add.cpp`

* Step 3: Check that the file exists
Create a shell block that lists the file `add.cpp`.

* Step 4: Compile the program using g++
Write a shell block that compiles the code into an executable called `add`.

* Step 5: Create an input file
- Create a file called `input.txt` with two numbers in it

* Step 6: Run the program with redirected input
Create a shell block that runs `./add < input.txt`.

* Step 7: Modify the program
- Change it to multiply the two numbers instead of adding
- Tangle, compile, and test again with the same input file

* Step 8: Reflection
Answer these in plain text:
1. What part of this was hardest?
2. What part are you most confident about?
3. What do you want to practice next?
