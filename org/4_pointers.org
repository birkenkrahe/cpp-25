* Getting the Address of a Variable

- The address-of operator ~&~ returns the memory address of a variable.

- Where exactly is this "memory address" on the computer?
  #+begin_quote
  It's in RAM (Random Access Memory) of the computer, usually
  somewhere in the "stack" or in the "heap".
  #+end_quote

- When the variable is undefined, you get any old value:
  #+begin_src C++ :main yes :includes <iostream> <cstdlib> <string> <fstream> <vector> :namespaces std :results output :exports both :noweb yes
    double amount; // double precision floating-point variable
    
    cout << "Address: " <<  &amount // address-of variable
         << ", value = " << amount  // value of variable
         << ", Size = " <<  sizeof(amount) << " bytes." << endl; // size of variable
  #+end_src

  #+RESULTS:
  : Address: 0x7ffe2c1314b0, value = 0, Size = 8 bytes.

- Why are the addresses always different?
  #+begin_quote
  Because of ASLR (Address Space Layout Randomization) - done for
  security reasons (harder to inject malicious code in changing
  memory).
  #+end_quote

- The following fragment declares three variables.
  #+begin_src C++ :main yes :includes <iostream> <cstdlib> <string> <fstream> <vector> :namespaces std :results none
    char letter;  // 1 byte   ( 8 bits)
    short number; // 2 bytes  (16 bits)

* Pointer Variables

- A pointer variable is a variable that holds a memory address. When
  it is used to point at data, its type has to coincide with the type
  of the data: An integer pointer can point at an integer, etc.

- When an array is passed to a function, it "decays" to a pointer to
  the first array element.

- What happens in the following code example with regard to variable
  addresses?
  #+name: pointer values
  #+begin_src C++ :main no :includes :results output :exports both
    #include <iostream>
    using namespace std;

    void showValues(int [], int);  // function prototype

    int main()
    {
      const int SIZE = 5;
      int numbers[SIZE] = {1,2,3,4,5}; // initialize array of SIZE elementsx
      showValues(numbers,SIZE); // call function
      return 0;
    }

    void showValues(int values[], int size)
    {
      for (int count = 0; count < size; count++)
        cout << values[count] << " ";
    }
  #+end_src

  #+RESULTS: pointer values
  : 1 2 3 4 5 

- Explanatinaon:
  #+begin_quote
  1. In ~main~, the name of the array numbers and its =SIZE= are passed to
     the function showValues
  2. In the function, the =values= parameter receives the address of the
     array =numbers= - it points to =numbers[0]=
  3. Inside showValues, anything done to =values= is done to =numbers=.
  #+end_quote

* Pointers vs. references and reason for pointers

- Pointer variables are similar to reference variables but they
  require more work from you.

- To make a pointer variable reference another item in memory, you
  have to write code to *fetch* the memory address of that item and
  *assign* it to the pointer variable (using the address-of operator
  ~&~).

- When you use a pointer to *store* a value in the memory location that
  the pointer references, you have to specify that it should be stored
  at a location rather than in the pointer variable itself (using the
  indirection or dereference operator ~*~).

- Programmers use reference variables to make changes permanent
  between calling routines and functions. But why use pointers?
  #+begin_quote
  1. Pointers are necessary when you want to allocate memory
     dynamically.
  2. Pointer are useful in algorithms that need to manipulate arrays
     fast and especially text (stored in strings).
  3. In object-oriented programming (OOP), pointers are useful to
     create and work with objects and for sharing access.
  #+end_quote

- Example: Walking through a string using a pointer
  #+begin_src cpp :main no :includes :results output :exports both
    #include <iostream>

    int main() {
      const char* greeting = "Hello, world"; // Declare a C-style string as constant (literal) character pointer.
      std::cout << greeting << std::endl; // Print the whole string.

      // The pointer points at greeting[0].
      std::cout << *greeting << std::endl;// 'H'
      // Moving forward, the pointer points at greeting[1]
      std::cout << *(greeting + 1) << std::endl; // 'e'

      // Traverse the C-style string with a pointer
      const char* p = greeting;
      while( *p != '\0') // check if the char pointed at is \0
        {
          std::cout << *p;
          ++p;  // move pointer to next memory cell (byte)
        }
      
      return 0;
    }
  #+end_src

  #+RESULTS:
  : Hello, world
  : H
  : e
  : Hello, worldello, worldllo, worldlo, worldo, world, world worldworldorldrldldd

* Creating and using pointer variables

- What does =int* ptr;= mean?
  #+begin_quote
  1. =ptr= is a pointer variable that points to an =int= variable.
  2. =ptr= can hold the value of a memory address (of 4 bytes).
  3. =ptr= at the moment is unassigned (it can point anywhere).
  #+end_quote

- What's the difference between =int* ptr= and =int *ptr= ?
  #+begin_quote
  There is none. 
  #+end_quote

* Why you can step through arrays using pointers
#+attr_html: :width 600px :float nil:
#+caption: Array elements are stored in contiguous memory locations (Gaddis Fig. 9-5)
[[../img/memory_storage.png]]

When you add a value to a pointer, you are adding that value times
the size of the data type being referenced by the pointer -
=*(number + 1)= moves 2 bytes forward when =number= is a ~short~ variable,
and 4 bytes when it is an ~int~ variable: So =*(number +1)= is actually
=*(number + 1 * sizeof(short))= etc.
#+attr_html: :width 600px :float nil:
#+caption: Subscript vs. pointer notation (Gaddis Fig. 9-6)
[[../img/memory_storage2.png]]

Length of ~short~ vs. length of ~int~:
#+begin_src C++ :main yes :includes <iostream> <cstdlib> <string> <fstream> <vector> :namespaces std :results output :exports both :noweb yes

  cout << "Size of short: " << sizeof(int)   << " bytes.";
#+end_src

: Size of short: 2 bytes.

But the whole operation works because moving like that through
memory makes the pointer point at the next array element.
