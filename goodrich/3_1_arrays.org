* Storing Game Entries in an Array

- We want to store a sequence of high score entries for a video game
  in an array. Records for hospital patients or the names of players
  on a football team would be analogous examples.

- We develop a =Scoreboard= class to store a certain number of high
  scores (depending on the game).

- Once the score limit is reached, a new score qualifies for inclusion
  if it is higher than the lowest score on board. Entries will be
  stored from highest to lowest score. In the case of a tie, the score
  entered first will appear ahead of another.

- An entry contains a string with the name of the player, and an
  integer with the player's score. A player may have more than one
  entry on the high-score board (if they play the game often enough).

* Representing high score entries

- We have to store a ~string~ =name= and an ~int~ =score= for each entry. We
  could maintain two (parallel) separate arrays for names and scores.

- What's the problem with this two-array approach?
  #+begin_quote
  If we fail to keep the array items aligned then this representation
  would become inconsistent.
  #+end_quote

- Instead, we develop a single composite data type that encapsulates
  both a =name= and a =score=, and a single array of those composite objects.

- What's another advantage of this approach?
  #+begin_quote
  If we want to add another field for statistical purposes, e.g. the
  date, or additional player data, we can adapt our class easily.
  #+end_quote

- Solution:

      : name(n), score(s) { }

- Explanations:
  #+begin_quote
  1) Externally defined member functions need to be brought in scope
     with the scope resolution operator (~::~) so that the compiler
     knows where to look for the ~class~ declaration.

  2) The constructor initializes =name= and =score= with a list. An
     alternative implementation would be:
     #+begin_example C++
      GameEntry::GameEntry(const string& n, int s)
      {
        name = n;
        score = s;
      }
     #+end_example

  3) The ~string~ argument is passed as a *reference*. References are
     alternative names for an (existing) object (see code example).

  4) The code block with the member function implementation will not
     compile because it cannot find the ~class GameEntry~ declaration
     without help.
  #+end_quote

* Developing a =Scoreboard= class for high scores

The code is presented in named code chunks, which are concatenated for
the full code further below. To do this, you need to have unique names
and switch on the =:noweb yes= Org-mode code block header argument.

The plan:

- We represent a scoreboard as an array of =GameEntry= instances, and
  use integers to represent current number of entries (=num_entries=)
  and overall =capacity= (initially 10) for entries.

- Since we do not know the array capacity (an argument to the
  constructor) in advance, we manage the array with a pointer =board= to
  a =GameEntry= object, and dynamically allocate the array during
  construction when the =capacity= is known.

- We provide accessor functions =get_capacity()=, =get_num_entries()=, and
  =get_entry(i)=, each of which is declared as a ~const~ function of the

- The ~class~ definition includes *inline* member function definitions.

* The =Scoreboard= ~class~

To recap: Each =Scoreboard= object has a =capacity=, a certain number of
actual entries =num_entries=, and each entry is a =GameEntry= ~class~
object, which is accessed through the =board= pointer.

#+NAME: SCOREBOARD_H
#+BEGIN_SRC C++ :tangle ../src/Scoreboard.h :main yes :includes <iostream> <cstdlib> <string> <fstream> <vector> :namespaces std :results none :exports both :noweb yes
  <<GAME_ENTRY_H>>

  // Class for storing high scores ordered within an array
  class Scoreboard {
  private:
    int capacity;           // capacity of the array
    int num_entries{0};     // number of actual entries (init 0)
    GameEntry* board;       // pointer to array of game

  public:
    // Constructs an empty scoreboard with given capacity for entries
    Scoreboard(int cap = 10)
      : capacity{cap}, board{new GameEntry[cap]} {};

    // Returns the capacity of the scoreboard
    int get_capacity() const { return capacity; }

    // Returns the number of current entries stored
    int get_num_entries() const { return num_entries; }

    // Returns a reference to the entry at index i
    const GameEntry& get_entry(int i) const { return board[i]; }
  };
#+END_SRC

* Glossary

| TERM                 | EXPLANATION                                       |
|----------------------+---------------------------------------------------|
| ~class~                | A data container                                  |
| ~public~               | Data accessible from anywhere                     |
| ~private~              | Data accessible only with class member functions  |
| ~const~                | No changes are allowed                            |
| member function      | A function inside the class to manipulate data    |
| constructor          | A member function to create a class object        |
| accessor/getter      | A member function to extract private data         |
